# Sand Circuit: The Last Grain

[English](README.md)

> 在最后一粒沙落下前，把时间导向武器。

**Sand Circuit: The Last Grain** 是为 GMTK Game Jam 2026 主题 **Count Down** 制作的线路构筑塔防
游戏。时间既是生命值，也是驱动钟表防御工坊的核心资源。

## 游戏玩法

把模块放到棋盘上，引导能量球穿过各种机器，为防御塔充能。敌人从右侧来袭；任何敌人抵达
沙漏都会夺走宝贵时间。设计高效线路、组合状态效果，并在最后一粒沙落下前守住 25 个逐渐
增强的波次。

当前 Game Jam 版本包含：

- 17 种攻击、路径、经济、附魔和辅助模块
- 购买、放置、旋转、移动、合成、升级和分解系统
- 灼烧、寒冷、融化、黑洞、炸弹和沙 buff 等战斗互动
- 随机构筑模块、发射器强化、祝福与束缚
- 带警告状态的 60 格世界空间倒计时环
- 钟表主题模块与怪物皮肤，以及灼烧、冰冻、沙粒、命中、死亡和融化特效
- 默认英文界面，可在游戏内切换简体中文

## 操作

- **鼠标：**购买、选择、拖动、放置、移动、合成和分解模块
- **R：**旋转当前选择或携带的模块
- **Space** 或 **准备按钮：**结束准备并开始下一波
- **F：**刷新商店
- **右键** 或 **X：**拆除已放置模块
- **中文 / EN：**切换语言；选择会保存到下次启动

## 本地运行

Windows: 游戏运行文件在Play文件夹; 或者可以解压缩游戏压缩包。

Mac: 解压或者下载到app文件夹后输入
```text
chmod -R +x TimeSands.app
xattr -cr TimeSands.app
```
更改权限后即可打开

数值表请见Docs
