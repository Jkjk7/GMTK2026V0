## 本地运行教程
### 环境依赖


### 步骤
1. 克隆仓库到本地
```bash
git clone https://github.com/Jkjk7/GMTK2026V0.git
```
2. 使用对应引擎打开项目根文件夹
3. 打开主场景，点击运行按钮即可测试游戏

## 打包发布
1. 在引擎内打开 Build 设置
2. 选择目标平台（Windows/Mac/WebGL）
3. 输出到 Build 文件夹，生成可执行文件
