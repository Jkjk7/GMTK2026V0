# Countdown — 游戏策划案（精简）

> 项目：GMTK2026 塔防原型 · 公开说明  
> 一句话：**用沙漏生命驱动能量球，在棋盘上铺电路喂塔，撑过 26 波（终局 Boss）。**

---

## 1. 定位

| 项 | 内容 |
|----|------|
| 品类 | Roguelike 元素的电路式塔防 |
| 视角 | 2D 俯视；左棋盘、上战斗道、右侧商店/手牌 |
| 单局时长 | 约 26 波；失败=沙尽（或 Boss 漏入本家），胜利=清完波 26 且沙未尽 |
| 风格 | 工厂 / 能量 / 沙漏时间；原型向可读命名（查理激光、大卫炸弹等） |

核心差异于传统塔防：塔不自动产蓝，**必须靠熔炉烧沙射球、路径把球送到塔**才有输出。

---

## 2. 核心循环

```
准备：买牌 → 放置/旋转路径与塔 → Ready
  → 倒计时 → 战斗：熔炉抽沙射球 → 球喂塔 → 塔打怪
  → 清波：金币（+偶发三选一成长）→ 下一波准备
```

**生命资源 = 沙漏时间**（开局约 100 秒量级）。战斗中熔炉持续抽沙换能量球；漏怪额外罚沙。普通击杀与清波都不回沙，只有特殊「沙 buff」怪击杀回沙——鼓励少漏、组好能量回路，并把回沙压在主动击杀沙怪上。

---

## 3. 三大系统

### 3.1 棋盘与能量

- 7×7 逻辑棋盘，可建造区可从 3×3 扩到 5×5、7×7。
- 熔炉从左侧入口射球；收束器等路径模块改向；可组环提高投能次数。
- 有效输出近似：**出球率 × 每球投能次数 × 伤/能**（无环远弱于有环）。
- 球寿命随熔炉档位：12 / 20 / 32 / 50 秒。

### 3.2 模块（构筑）

| 角色 | 例子 |
|------|------|
| 路径 | 收束器、传送门、加速、中续、分裂/聚变/裂变 |
| 攻击 | 激光、炸弹、激光炮、雪花（寒）、火花（烧）、奥数飞弹、黑洞、热浪、冰霜冻结、烈焰墙 |
| 辅助 | 采矿、火焰/寒冰增幅、格附魔、消耗型道具（净化等） |

- 同型同级可合成升级；部分路径可与收束器合成「拐弯版」。
- 火花 + 雪花可触发**融化**（额外爆发并清除烧/寒）。
- 开火间隔统一受地块附魔影响（缩小加快、虚弱减慢）；UI 只显示「射速」。

### 3.3 成长（台阶）

| 节奏 | 内容 |
|------|------|
| 前 15 波每 3 波、之后每 2 波 | 模块解锁三选一（扩商店池；终局波不发） |
| 每 5 波（含 25） | 熔炉四维升级（容量/球速/质量/寿命） |
| 每 5 波（含 25） | **祝福 + 束缚**捆绑三选一（有得有失；可含战场/手牌模块升稀有度） |

开局池保证能开火：激光、收束器、雪花、火花。前几波故意偏缓，给无环教学窗口。

---

## 4. 敌人与压力

- 红（常规）/ 黄（快而脆）/ 蓝（慢而肉）；后期混紫拆、金盾。
- 血量每 5 波跳档（10→25→60→120→200）；数量与刷怪间隔随波上升。
- **波 26：终局 Boss（10 000 HP）**；Boss 漏入本家 = 立刻败北。
- 漏怪：立刻扣沙 + 失去完美清波金；回沙仅来自沙 buff 击杀。

详细数值见同目录 `数值平衡表.md`。

---

## 5. 体验目标（锚点）

| 阶段 | 期望手感 |
|------|----------|
| 波 1–5 | 学会铺路与开火，直铺可过 |
| 波 5–10 | 小环稳定；首次熔炉与祝福束缚 |
| 波 12–15 | 升级/合成与控场开始必要 |
| 波 20–25 | 多层束缚下靠构筑与资源管理压完怪潮 |
| 波 26 | 终局 Boss 决战 |

---

## 6. 非目标（当前原型不做）

- 复杂剧情战役、多地图、完整成就系统  
- 传统「心数 / 多命」替代沙漏  
- 以塔 DPS 简单相加作为平衡模型
