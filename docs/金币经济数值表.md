# 金币经济数值表

> 局内整数金币经济（无局外货币）。基准：2026-07；**Gcoin3 修订**：每波准备、拆除确认、禁棋盘拖动、功能拆除 6%。

## A2. 会话状态（Gcoin3）

| 属性 | 含义 | 典型用途 |
|------|------|----------|
| `IsPreparing` | 准备阶段 | 免费拆除、棋盘合成、停发射器 |
| `IsCombatActive` | 战斗刷怪 | 发球、敌人移动、付费拆除 |
| `IsRunActive` | 准备或战斗 | 商店、放置 |

## B. 波次预算

```text
waveGoldBudget = round(14 * 1.065^(wave-1) + 6)
```

分配：击杀 70% / 清波 20% / 完美 10%。漏怪清屏不掉杀金币。

## C. 准备时间（Gcoin3）

| 波数 | 普通准备 | 逢 5/10/… 大波 |
|---:|---:|---:|
| 1～5 | 20s | +15s |
| 6～10 | 25s | +15s |
| 11～20 | 35s | +15s |
| 21～30 | 45s | +15s |
| 31～40 | 60s | +15s |
| 41～50 | 75s | +15s |

`ModulePricing.GetPrepSeconds`。可 Space/按钮跳过 → ~1.5s `3→2→1→开始`。无提前完成金币奖。

准备阶段：发射器停、清能量球、攻击模块清储能。

## D. 拆除（Gcoin3）

棋盘可拖移（战斗中按拆除费率确认）；可拖入分解区确认永久分解。

| 时机 | 费用 |
|------|------|
| 准备 | **0**（仍二次确认） |
| 战斗·攻击 | 参考售价 × **12%**（≥1） |
| 战斗·功能 | 参考售价 × **6%**（≥1） |

库存满 / 金币不足 → 不可拆。

## E. 分解（Gcoin3）

- 位置：棋盘外框**左下角**
- **库存**可分解（选中点或拖入）；**战场**也可直接拖入分解区
- 确认框「确认分解」后执行；按 `investedGold×30%`，有投入至少 1
- 战场分解会永久移除该模块（不回库存）

## F. 商店售价 / 刷新 / 货架

同前版：射弹 base 20、收束器 15（封顶 30）；刷新 `3+2×stage` 与连刷倍率；货架 4 攻 +1 功能 +1 随机。详见 `ModulePricing` / `ModuleCatalog`。
