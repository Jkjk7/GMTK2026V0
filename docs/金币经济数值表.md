## B. 波次（15 波 Demo）

点数：红=5，黄=1，蓝=20（**5 黄 = 1 红**）。

| 波段 | 构成 |
|------|------|
| 1–4 | 仅红 |
| 5–7 | 红黄 |
| 8–15 | 红黄蓝；8/12 保底蓝×1；10/15 保底蓝×2 |

预算约 `15 + 5×wave`（≥10 波额外 +10）。黄潮刷期间隔 ×0.55。

## C. 模块解锁

每 **3** 波结束（3/6/9/12）三选一加入本局池。候选：炸弹 / 寒冰 / 采矿。

池满时每个选项带 `(替换XXX)`（从已解锁中抽样，尽量不重复）；选中则换入新模块，场上旧模块不消失。
