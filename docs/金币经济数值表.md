## A2. 沙漏时间（生存资源，替代 3 命）

1 粒沙 = 1 毫秒；左侧沙漏上方显示 `mm:ss.mmm` 倒计时。**沙尽即败**；打完 25 波且沙 > 0 即胜。

| 项 | 值 |
|----|---:|
| 开局沙量 | **100,000 ms**（01:40.000） |
| 沙流失 | 仅战斗阶段：熔炉以 **1000 沙/秒**（实时）抽沙 |
| 熔炉容量 | 攒满 **capMs** 结晶 1 枚能量球（开局 2000ms ≈ 2 秒一球） |
| 漏怪罚沙 | 黄 **−3,000** / 红 **−10,000** / 蓝 **−30,000**（按只，不清屏） |

补沙（`SandClock.BeginWave` 按波换算）：

```text
estDrain = (刷怪间隔 × (N−1) + 10s通行) × 1000 ms
击杀池   = 0.75 × estDrain（按点数权重红5/黄1/蓝20 分到每只）
清波奖   = 0.35 × estDrain
```

零漏一波约净 **+10%**；漏怪双重损失（罚沙 + 少拿击杀补沙）。源码：`SandClock.cs`。

|------|---------------:|---------:|------------------------|
| 1–5 | 0 | — | ×1.0 |
| 6–10 | 2±1 | 8s | ×1.3 |
| 11–15 | 3±1 | 11s | ×1.65 |
| 16–20 | 3±1 | 14s | ×2.1 |

## C. 波次金币预算

```text
预算 = max(20, RoundToFive(round(18 × 1.205^(w-1))))  // w 钳制 1–25
```

约：波1=20、波5=40、波10=100、波15=250、波20≈640、波25≈1635。

拆分：击杀池 **70%** / 清波 **20%** / 完美防守 **剩余**。清屏/漏怪强制消失不掉击杀金。

## D. 商店（稀有度 + 每 5 波一大跳）

`stage = (wave-1)//5` → 波1–5=0 … 波21–25=4。

稀有度：

| 稀有度 | 模块 | 价倍率 | 升级指数 |
|--------|------|-------:|--------:|
| 普通 | 激光 / 寒冰 / 炸弹 | 1.0 | 2.25 |
| 稀有 | 收束器 / 采矿 | 1.5 | 2.35 |
| 史诗 | **黑洞发射器** | 2.5 | 2.60 |
| 传奇 | （暂无实体；祝福抽到则降级史诗） | 4.0 | 2.85 |

```text
stageMult = 1.80^stage
攻击价 = Round5(基础 × lvExp^(Lv-1) × stageMult × rarityMult)
功能/采矿 = Round5(基础 × … × stageMult × rarityMult)
刷新费 = 5 + stage×(7+stage)  // 同阶段恒定
商店权重 = baseWeight[rarity] × stageBias（高稀有更难出，后期略抬）
```

波末进入准备（波≥2）**免费自动刷新**一次。

## E. 模块解锁 / 熔炉 / 祝福束缚

清波草稿链：`模块解锁(每3波) → 发射器(每5波) → 祝福+束缚组合(每5波)`。

- 模块解锁：波 3/6/9/…/24；候选炸弹/采矿；**波≥6 含火焰增幅**；**波≥9 含黑洞**（寒冰/火花已开局解锁）。
- 熔炉升级：波 5/10/15/20。
- 祝福+束缚：波 5/10/15/20；一张卡 = 一祝福 + 一束缚，三选一。
- 熔炉容量档：**2000 → 1400 → 1050 → 800**。
