## C. 波次金币预算

```text
预算 = max(20, RoundToFive(round(18 × 1.205^(w-1))))
```

约：波1=20、波5=40、波10=100、波15=250。

拆分：击杀池 **70%** / 清波 **20%** / 完美防守 **剩余**。清屏/漏怪强制消失不掉击杀金。

## D. 商店（每 5 波一大跳）

`stage = (wave-1)//5` → 波1–5=0，6–10=1，11–15=2。

```text
stageMult = 1.80^stage   // 1 → 1.8 → 3.24
攻击价 = Round5(基础 × 2.25^(Lv-1) × stageMult)
功能/采矿 = Round5(基础 × … × stageMult)  // 功能不再 2× 封顶
刷新费 = 5 + stage×(7+stage)  // 5 / 13 / 23，同阶段恒定
```

| 示例（Lv1） | 波1–5 | 波6–10 | 波11–15 |
|-------------|------:|-------:|--------:|
| 激光基础20 | 20 | 35 | 65 |
| 收束器15 | 15 | 25 | 50 |

波末进入准备（波≥2）**免费自动刷新**一次。
