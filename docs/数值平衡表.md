## 4. 经济

```text
波金币预算 = max(20, Round5(round(18 × 1.205^(w-1))))   // w ∈ 1..25
击杀池 70% / 清波 20% / 完美(零漏) 剩余
```

约：波1=20，波5=40，波10=100，波15=250，波20≈640，波25≈1635。

击杀掉落区间（再受击杀池封顶）：黄 0–1 / 红 1–3 / 蓝 3–7。

### 商店价

```text
stageMult = 1.80^stage
攻击 = Round5(base × lvExp^(Lv-1) × stageMult × rarityMult)
矿机 = Round5(base × (1+0.35×(Lv-1)) × stageMult × rarityMult)
增幅/附魔 = Round5(base × (1+0.4×(Lv-1)) × stageMult × rarityMult)
其他功能 = Round5(base × stageMult × rarityMult)
刷新费 = 5 + stage×(7+stage)
```

稀有度价倍：普通 1 / 稀有 1.5 / 史诗 2.5 / 传奇 4。  
升级指数：2.25 / 2.35 / 2.60 / 2.85。

## 6. 模块战斗要点

| 模块 | 要点 |
|------|------|
| 激光 | 伤 Round(5×1.8^(Lv-1))；储能 5+2×(Lv-1)；基础约 5 发/秒；最近敌人 |
| 炸弹 | 伤 Round(15×1.5^(Lv-1))；最左敌人 AOE；耗 5 |
| 雪花 | 伤恒 5；寒 30%；时长 2+(Lv-1)s；耗 1 |
| 火花 | 伤 1/1/2/2/3；烧 2+0.5×(Lv-1)s；耗 1 |
| 黑洞 | 耗 5 / 容 5 / 3 秒一发；吸引聚怪 |
| 热浪 | 容耗 20；CD 5 s；全屏烧 2/3/4/5 s |
| 矿机 | 10 能 → 金 1/3/8；CD 3 s |
| 火焰增幅 | 灼烧 +1/3/5/7/10 |
| 加速 | 球速 ×1.5（每球一次） |
| 中续 | 储能 cap 20；下一球刷新寿命 |
| 聚变 | 5 球 → 1（Σ能，均寿均速） |
| 裂变 | ≥5 能 → 0.5 s 射 5×(能1/寿12/速8) |
| 分裂 | 2 球，剩余寿命 ×0.5；不可拐弯合成 |
| 传送门 | 场上 ≤2；成对保方向传送 |

融化：烧+寒相遇下一发 ×1.5 并清除双状态。  
收束器 × {传送门,中续,加速,聚变,裂变} → 同类型拐弯版（Bent）。
