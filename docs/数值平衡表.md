## 4. 经济

```text
波金币预算 = max(20, Round5(round(18 × 1.205^(w-1))))   // w ∈ 1..26
击杀池 70% / 清波 20% / 完美(零漏) 剩余
```

约：波1=20，波5=40，波10=100，波15=250，波20≈640，波25≈1635，波26≈1970。

击杀掉落区间（再受击杀池封顶）：黄 0–1 / 红 1–3 / 蓝 3–7。

### 商店等级与货架

```text
shopLevel = (wave - 1) // 5 + 1
  波 1–5 → Lv1；6–10 → Lv2；11–15 → Lv3；16–20 → Lv4；21–25 → Lv5；26 → Lv6

货架可出模块等级：
  奇商店级：仅 (shopLevel+1)/2     （Lv1→1，Lv3→2，Lv5→3…）
  偶商店级：(shopLevel/2) ~ +1     （Lv2→1–2，Lv4→2–3…；双档约 40%/60% 偏高）
刷新费 = 5 × ((shopLevel + 1) / 2)   // Lv1–2→5，Lv3–4→10…
```

### 商店价（同等级固定，不随波次涨价）

```text
攻击 = Round5(base × lvExp^(Lv-1) × rarityMult)
矿机 = Round5(base × (1+0.35×(Lv-1)) × rarityMult)
增幅/附魔 = Round5(base × (1+0.4×(Lv-1)) × rarityMult)
其他功能 = Round5(base × rarityMult)
```

稀有度价倍：普通 1 / 稀有 1.5 / 史诗 2.5 / 传奇 4。  
升级指数：2.25 / 2.35 / 2.60 / 2.85。

## 5. 成长节奏

| 事件 | 波 |
|------|-----|
| 模块解锁三选一 | 前段每 3 波：3, 6, 9, 12；之后每 2 波：16, 18, 20, 22, 24（不含终局波 26） |
| 熔炉升级 | 5, 10, 15, 20, 25 |
| 祝福+束缚（捆绑） | 5, 10, 15, 20, 25 |

解锁候选要点：波≥6 火焰增幅；波≥9 黑洞/聚变/裂变/激光炮；波≥12 分裂器。寒冰/火花已在开局池。  
商店六格均按稀有度权重从全解锁池抽取（无攻击/功能槽偏好）。

祝福示例：`UpgradeModules` 将战场或手牌中若干模块变为高一级稀有度的随机模块（道具不作来源/目标）。

准备阶段：无时限，玩家按「准备完毕」/ Space 后进入 3-2-1 开战。

## 6. 模块战斗要点

射速统一：攻击模块无敌人时不耗能/不开火（储能条可见）。Tooltip 只显示「射速」一栏。

| 模块 | 要点 |
|------|------|
| 激光 | 伤 Round(5×1.8^(Lv-1))；容 5；耗 1；约 5 发/秒；最近敌人 |
| 炸弹 | 伤同激光；容 5；耗 5；1.5 发/秒；最左 AOE |
| 激光炮 | 伤 30/60/100/150/200；容 5；耗 5；1 发/秒；厚激光 |
| 雪花 | 伤 Lv1=5，其后 10；寒基础减速 30%；时长 2+(Lv-1)s；容 5；耗 1；5 发/秒 |
| 火花 | 伤 5/10/15/20/30；烧 2+0.5×(Lv-1)s；容 5；耗 1；5 发/秒 |
| 奥数飞弹 | 伤 10/20/30/50/80；容 5；耗 1；5 发/秒；紫弹索敌最右 |
| 黑洞 | 耗 5 / 容 5 / 间隔 6 s；吸引聚怪 |
| 热浪 | 容耗 20；间隔 5/4.5/4/4/3 s；全屏烧时长 2 s（Lv1–3）/ 3 s（Lv4–5） |
| 冰霜冻结 | 同热浪间隔与时长；全屏[寒冷]（基础减速 30%） |
| 矿机 | 容/耗 10；间隔 3 s；金 5/10/20（最高 Lv3） |
| 火焰增幅 | 灼烧跳动 +1/3/5/7/10 |
| 寒冰增幅 | 寒冷减速每级 +5%，总减速上限 70% |
| 烈焰墙 | 容 30；穿墙伤 5/10/15/29/50；挂烧 2/2/3/4/5 s |
| 加速 | 球速 ×1.5（每球一次） |
| 中续 | 穿过汲能至 20；满后刷新寿命（不吞球） |
| 聚变 | 5 球 → 1（Σ能，均寿均速） |
| 裂变 | ≥5 能 → 0.5 s 射 5×(能1/寿12/速8) |
| 分裂 | 2 球，剩余寿命 ×0.5；不可拐弯合成 |
| 传送门 | 场上 ≤2；成对保方向传送 |

融化：烧+寒相遇下一发 ×1.5 并清除双状态。  
收束器 × {传送门,中续,加速,聚变,裂变} → 同类型拐弯版（Bent）。
