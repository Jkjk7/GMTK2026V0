### 刷新费

### 商店价公式

```text
stageMult = 1.80^stage
攻击 = Round5(base × lvExp^(Lv-1) × stageMult × rarityMult)
矿机 = Round5(base × (1+0.35×(Lv-1)) × stageMult × rarityMult)
增幅/附魔 = Round5(base × (1+0.4×(Lv-1)) × stageMult × rarityMult)
其他功能 = Round5(base × stageMult × rarityMult)
```

稀有度价倍：C1 / R1.5 / E2.5 / L4。  
升级指数 lvExp：C2.25 / R2.35 / E2.60 / L2.85。

## F. 改参建议（给数值 Agent）

1. **前中期太难**：先动 `NormalCounts`/`SwarmCounts`/`SpawnIntervals`（波1–10），再动漏怪倍率。
2. **后期泄**：加数量或缩短间隔，或抬 HP 档，勿只加单怪血导致激光手感崩。
3. **经济崩**：同时看 `WaveGoldBudget` 与 `stageMult=1.8`；只改一边会通胀/通缩。
4. **出球洪水**：优先动熔炉容量档或球上限，勿轻易把质量拉回旧 1/2/5/10。
5. 每次改动写 3 句：改了什么 / 期望手感 / 怎么验证（对照锚点表）。
