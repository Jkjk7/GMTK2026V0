# 05 — 战斗：敌人 · 波次 · 伤害

## 1. 战斗空间

- `BattleLane`：右侧刷怪锚点 → 左侧终点（与沙漏列对齐）。
- 敌人沿 X 向左移动；`x <= EndX` 视为破防（breach）。
- `Mage`：终点占位；实际罚沙走 `SandClock`。破防**不扣心、不清屏**。
- 破防会：`WaveGoldBudget.NotifyBreach()` → 本波失去「完美防守」金。

## 2. 敌人类型（`EnemyGoldType`）

| 类型 | 外观倾向 | 移速 | HP | 备注 |
|------|----------|------|-----|------|
| Normal 红 | 小 | 1.5 | 红HP表 | 主流 |
| Swarm 黄 | 更小 | **3.0** | ⌈红×0.5⌉ | 刷怪间隔再 ×0.55 |
| Tank 蓝 | 更大 | 0.75 | 红×4 | 中后期 |
| Boss 橙 | 巨大 | 0.75 | **100_000** | 仅波 25 队尾 |

移速再乘 `RunModifiers.EnemySpeedMult`（束缚可叠，上限 1.5×）。

### 红 HP 档（每 5 波跳）

波 1–5:**10** → 6–10:**25** → 11–15:**50** → 16–20:**80** → 21–25:**130**。

## 3. 沙 buff（附着，不是新怪种）

- 刷怪队列生成后，按 `SandBuffBaseCounts[wave]` ±1 随机挂到非 Boss 条目。
- 波 **1–5：0**；之后 2/2/2/2/2 → 3… → 4…（见 `07` 表）。
- 效果：HP ×**1.5**；漏怪罚沙 ×**1.5**；击杀才爆沙；青白发光闪烁。

## 4. 波次刷新（`WaveSpawnBudget` + `WaveManager`）

1. `BuildQueue(wave)`：按红/黄/蓝配额填表 → Shuffle → 挂沙 buff →（波25）加 Boss。
2. 按 `SpawnIntervals[wave-1]` 刷一只；若刚刷的是黄，间隔 ×**0.55**。
3. 队列刷完且场上无活怪 → 清波。

**前 5 波设计意图**：无环也能过；波 5 只给 4 黄试水，无沙 buff。

完整 25 波数量与间隔见 [`07-balance-tables.md`](07-balance-tables.md)。

## 5. 伤害管线（`CombatDamage.Apply`）

```
rawDamage
  × DamageUp(1.2) 或 Shrink(0.5)   // 来源塔所在格附魔
  若融化：再 ×1.5，弹 "Melt"，ClearBurnAndChill，本发不再挂状态
  否则：按 fx / 附魔挂 Burn / Chill
```

### 灼烧（`Enemy`）
- 每 **0.5s** 跳一次。
- 每跳伤害 = `BaseBurnDamagePerTick(3) + BurnDamageBonus(祝福) + FlameAmpBonus(场上增幅)`。

### 寒冷
- `ApplySlow(percent, duration)`；雪花默认 30%。

### 融化（Melt）
- 条件：本发是寒且目标在烧，或本发是烧且目标在寒。
- 结果：伤害×1.5，清除双状态，**本发不重新挂烧/寒**。
- 设计组合：火花 + 雪花。

## 6. 索敌差异（平衡时注意）

| 塔 | 索敌 |
|----|------|
| 激光 / 黑洞 / 雪花 / 火花 | 多为最近或锁定追踪 |
| 炸弹 | **最左**敌人位置 |
| 热浪 | 全屏，无索敌 |

黄潮考验的是「到达时间 + 堆叠」，不只是总 HP。
