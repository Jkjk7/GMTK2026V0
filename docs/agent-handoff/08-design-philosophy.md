# 08 — 设计哲学、思路与坑

## 1. 设计一句话

> 用生命（沙）换能量球，用路径把球喂给塔，用塔换清波与回沙；成长有得有失（祝福绑束缚）。

## 2. 为何「无环就打不过」是预期

有效 DPS 近似：

```
熔炉出球率 × 平均每球投能次数（环路） × 伤/能
```

直铺单塔：每球只喂一次。  
四收束小环：同一球可多次进塔 → 指数级体感差异。  
因此前 5 波被刻意削弱（见 `07`），给玩家学铺路的窗口；波 6+ 开始要求路径意识。

## 3. 沙漏设计意图

- **主动消耗**：想输出必须烧沙 → 紧张感。
- **漏怪双重惩罚**：立刻扣沙 + 失去沙buff击杀回沙 + 失去完美金。
- **回沙稀缺**：普通击杀不补沙，只有沙buff怪与清波/祝福 → 鼓励「尽量不漏」而非无脑清屏。

## 4. 模块设计簇

| 簇 | 目的 |
|----|------|
| 激光 | 基准单体，升级指数伤 |
| 炸弹 | 打最左，清潮/堵漏 |
| 雪花+火花 | 控制+灼烧，组合融化 |
| 黑洞 | 后期聚怪，给 AOE 窗口 |
| 路径功能 | 延长球寿命、加速、传送、聚变裂变改变能量形态 |
| 附魔/热浪/增幅 | 灼烧流派横向强化 |
| 矿机 | 经济，但耗能量与占格 |

## 5. 稀有度与解锁节奏思路

- Common 开局即可用，解决「能开火」。
- Rare 路径/辅助在草稿里陆续出现，解决「球怎么走」。
- Epic 控场与能量变态模块偏后，避免开局爆炸。

## 6. 常见坑（Agent 易踩）

1. **按传统 TD 加塔伤** → 无环仍过弱、有环过强。应同时考虑投能次数。  
2. **忘了准备阶段清储能** → 下一波开局满储能瞬秒。新储能模块必须进 `ClearEnergyOnBoard`。  
3. **分裂/裂变同帧再触发** → 必须 nudge / mark cell。  
4. **传送门无限乒乓** → 同帧标记。  
5. **Bent 合成只改 CardData 不换组件** → 收束器格子合成传送门时必须换实例（已有 `TryApplyBoardFuse`）。  
6. **改枚举不改 Catalog/Placement** → 商店能刷出来但 CreateModule 返回 null。  
7. **把路线图文档当已实现** → 以代码为准。  
8. **黄怪间隔** → 基础间隔后还 ×0.55，调波 5/10 时别忽略。  

## 7. 代码风格约定（与现有一致）

- 新系统优先运行时 `AddComponent`，少依赖场景 Prefab。
- 中文 XML 注释说明职责。
- 数值集中在静态表 / Catalog / Pricing，避免魔法数散落在 Update。
- UI 文案中文；调试 Log 可用中英。

## 9. 对话历史中已落地、易被遗忘的决策

- 前 5 波难度已下调（红少、间隔慢、波5黄4、无沙buff）。
- 火花/雪花进开局池；基础价 15；解锁候选不再出它们。
- 灼烧跳伤基础 3/0.5s；融化不清后再挂状态。
- 质量档为 1/2/3/4（曾削弱自更高值）。
- 沙buff 爆沙与 TimeTax 曾砍半向数值。
- 功能路径模块 + 收束器 = 同 Type 的 Bent，不是新枚举。
- 球数 HUD：`当前/最大` 在棋盘上方。
